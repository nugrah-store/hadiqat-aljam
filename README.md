# حديقة الجمع

لعبة رياضيات عربية لطالبات الصف الثالث الابتدائي، تضم ١٧ محطة في القيمة المنزلية والأنماط والمقارنة والترتيب والتقريب والجمع والتعويض وإعادة التجميع.

عمل الطالبة: **بيسان إبراهيم**  
المعلمة: **روضة البركاتي**

تتضمن أسئلة فورية، وحلولًا متدرجة، وتلميحات، ونقاطًا وتقدّمًا محفوظًا على المتصفح. لا تحتاج إلى خادم أو مكتبات خارجية. ملف البداية هو `index.html`.

يُرفع المصدر إلى مستودع خاص. لم يُضف إعداد نشر تلقائي؛ يحتاج إتاحة الموقع للعامة إلى موافقة المالكة.
